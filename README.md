# VLSI-CAD-Tools
Python codes implementing some basic tools useful for logic synthesis, physical design and verification. <br>

1) Compiled Code Logic Simulator for SPICE-type netlists (supports both combinational and sequential logic) <br>
2) Combinational Logic Minimizer using ESPRESSO Heuristic <br>
3) Finite State Machine Minimizer using State Equivalence Checking and ESPRESSO Heuristic <br>


Planned upgrades, new tools- <br>
i) Combinational Logic Minimizer using ESPRESSO Heuristic with expression as input instead of truth-table <br>
ii) Reduced-Ordered Binary Decision Diagram for Combinational Equivalence Checking <br>
iii) Miter-based BFS for Sequential Equivalence Checking <br>
iv) DPLL SAT Solver for LTL property Checking <br>
v) PODEM Stuck-at-fault Test-vector Generator <br>
